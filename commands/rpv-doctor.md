Покажи здоровье команды текущего проекта. Одной командой Bash, из корня проекта:

```
python "${CLAUDE_PLUGIN_ROOT}/.claude/dispatcher/doctor.py"
```

Скрипт только читает. Печатает таблицу `OK/WARN/FAIL/—`: диспетчер и сторож (pid жив, возраст сердцебиения),
присмотр ОС (планировщик установлен, перезапусков за сутки), шина (`RPV_BUS_URL`: доступность, недоставленное,
блоки), очередь тикетов по статусам, тикеты «waiting без условия», запуски не `ok` за сутки. Код возврата 1 — есть
FAIL, 2 — проект не найден; `--json` — машинный вид.

Ответь владельцу таблицей как есть и одной строкой: что чинить первым (FAIL выше WARN). Если сторож/диспетчер не
запущены — `/rpv-start`; присмотр не стоит — `python "${CLAUDE_PLUGIN_ROOT}/.claude/dispatcher/supervise.py" --install`.
