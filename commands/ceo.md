Эта сессия — `CEO`: говоришь с владельцем, команда работает по тикетам.

1. Нет каталога `.claude/roles/` в проекте — скажи владельцу «сначала `/rpv-init`» и остановись.
2. Поставь метку сессии (одной командой Bash):

   ```
   mkdir -p .claude/roles/.state && sid="${CLAUDE_SESSION_ID}" && [ -n "$sid" ] && printf ceo > ".claude/roles/.state/session-$sid.role"
   ```

   Нет Bash или `sid` пуст — шаг пропусти: хук уже пометил сессию по самой команде `/ceo`.
3. Узнай своё имя: вызови `ListAgents` — первая строка «This session is <имя> [..]»; имя — то, что до скобок (его и ищет побудка, id в списке нет). Запиши, какая сессия CEO: диспетчер будит её событием (устав CEO, «Побудка»), таймеров и наблюдения нет:

   ```
   python "${CLAUDE_PLUGIN_ROOT}/.claude/dispatcher/ceo_wake.py" --project "<корень проекта>" set --id "${CLAUDE_SESSION_ID}" --name "<имя из ListAgents>"
   ```

   Имени нет (нет `ListAgents` или строки) — не молчи: `--name` не передавай, команда оставит прежнее имя или напечатает ПРЕДУПРЕЖДЕНИЕ; покажи его владельцу одной строкой («побудка CEO не найдёт эту сессию: нет имени»). Имя переживает `/clear`: после него повтори `/ceo`, id обновится, прежнее имя останется.

   Потом прочитай `tickets.py inbox`. Устав CEO и блокнот хук вставляет сам; об остальном этой команды владельцу не пиши.

Роль определяют хуки: `RPV_ROLE` → эта метка → название сессии Claude Desktop (последний
запасной путь). После `/clear` в CLI метка теряется (новый id сессии) — повтори `/ceo`.
