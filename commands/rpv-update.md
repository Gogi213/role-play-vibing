Обнови плагин `role-play-vibing` и всё, что на нём стоит, в текущем проекте. Только для CEO: синк уставов — его команда.

1. Слово владельца об обновлении сначала в реестр (`secretary`), номер решения — `В-N`.
2. Одной командой Bash, из корня проекта:

```
python "${CLAUDE_PLUGIN_ROOT}/.claude/dispatcher/update.py" --ref В-N
```

Скрипт по порядку: `claude plugin marketplace update` → `claude plugin update` → из НОВОЙ версии `start.py` (службы),
`supervise.py --install` (присмотр ОС, на macOS plist с PATH и `CLAUDE_BIN`), `tickets.py charter sync --ref В-N`
(уставы; без `--ref` шаг — FAIL), `doctor.py`. Версия не изменилась — сказано «уже последняя версия», службы и
`doctor` всё равно проверены, синк уставов пропущен. Код возврата 1 — есть FAIL.

Ответь владельцу таблицей скрипта как есть и последней строкой скрипта. Любой FAIL (в том числе у `doctor`) назови
как есть — «зелёным» обновление называть нельзя. Строку «Перезапустите Claude Code — до перезапуска сессия на старой
версии» передай без изменений: до перезапуска эта сессия работает на старых запретах и хуках.

- `${CLAUDE_PLUGIN_ROOT}` пуст (путь не подставился) — найди каталог плагина `role-play-vibing` под
  `~/.claude/plugins` (в нём `.claude/dispatcher/update.py`) и подставь его.
- Нет команды `python` — `python3` или `py -3`.
