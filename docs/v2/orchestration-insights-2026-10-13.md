## 3. Выводы

1. Зрелые проекты сходятся: **состояние вне модели (файлы/трекер/git), сессия одноразовая.** Наш `--resume` на тикет —
   выброс. → Сделано 13.10 05:45: `RPV_DISPATCH_ROTATE_TOKENS=1` — каждое пробуждение роли с чистого листа;
   подогрев кэша выключен.
2. **Зависания** закрывают жёсткими лимитами (шаги, тишина, бюджет) + детектором повторов + сверкой процессов.
3. **Многочасовые внешние задания не решает никто**; лучшее — «припарковать»: ожидание = данные, проверяет простой
   скрипт без токенов, по событию стартует свежая сессия. Наш «wait_for + rc-файл» — близко к этому.
4. **Круг «чиню-ломаю» явно не решён нигде;** живут проекты с малой поверхностью механики (Symphony — один SPEC,
   Beads — один граф). Растущая механика (Gas Town — роли множатся) сама плодит работу.
5. **Ревью — гейт на переходе состояния**, а не диалог ролей; петли режутся лимитом повторов.

## 4а. В плагин (бэклог; делать в проекте плагина, alpha берёт версию только в окне между проходами)

1. **Бабочка по умолчанию:** область сессии «запуск» (новая сессия на каждое пробуждение) как штатный режим вместо
   `--resume` на тикет; сейчас в alpha это обход через `RPV_DISPATCH_ROTATE_TOKENS=1`. Подогрев кэша (TK-226) при
   бабочках бесполезен — убрать.
2. **Отказ незаказанной работе:** `tickets.py new` требует ссылку на задачу владельца (цитата/решение В-##); без неё —
   отказ (как check_plan у autopilot).
3. **Потолок ремонта 2:** после двух возвратов Судьи — тикет закрывается «не сделано» с остатком в отчёт, а не
   blocked/владелец (сейчас 3 возврата → блок).
4. **Фильтр вопросов владельцу:** ask-owner только с поводом деньги/видимое/необратимое/бизнес-правило; иначе — Судье
   (TK-218 сделал часть: ask-owner не-Судьи → Судье).
5. **Ожидание заданий — только код завершения:** wait_for на файл-метку задания — отказ, не предупреждение.
6. **Автовыпуск не посреди работы:** проект может закрепить версию; обновление служб — только когда нет идущих
   запусков ролей (13.10: 6 выпусков за 7 ч, каждый перезапускал службы).
7. **Зависания:** лимит шагов на запуск и детектор повторов (одинаковые действие-ответ ≥ 4 раз) вместо одного
   таймаута 20 мин.
8. **Ежедневный отчёт по гайду** (закладка, журнал, «сбой источника ≠ тишина», перепроверка) — шаблон задачи по
   расписанию в плагине; в alpha уже есть `.claude/brief/` + задача alpha-daily-brief.

## 4. Что берём (по слову владельца)

- **Принято:** отказ работе, которую владелец не заказывал (тикет без ссылки на задачу владельца / В-## — не заводится).
- **Сделано:** роли — бабочки (свежая сессия на пробуждение).
- **Правило CEO:** ремонт инфраструктуры только если стоит счёт; одна правка за раз в окне между проходами;
  не больше 2 попыток починить одно — дальше откат к простому варианту и строка в отчёт.
- **Вопросы владельцу** — только деньги, видимое ему, необратимое, бизнес-правило.
- **Не делаем сейчас:** перенос ролей на встроенных помощников без плагина (владелец не решил), детектор повторов,
  слепая приёмка Судьи.
