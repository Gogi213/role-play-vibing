**Как идёт работа.** Чекпоинты — подряд, без вопроса «начинать?»: план утверждён. Остановка — только на решении
владельца, и тогда первой строкой «Стою: жду вашего …». Простой 13.10 после CP2 (ждал «да» на уже утверждённое) —
нарушение этого правила; то же правило записано CEO в устав (`templates/roles/ceo.md`), тревога «готовая работа
стоит» (CP5) ловит такой простой в самой команде.

Механически не ловится — честно: трата денег (покупка серверов, платные сервисы) не распознаётся по команде; её держат
повод `ask-owner деньги` и проверка Судьи. Список запретов на публикации (CP2) тоже не закрывает всё: выкатку по ssh
на чужие сервера, произвольные HTTP-запросы к другим сервисам и обходы через скрипты (код на Python, Node, Ruby,
команда, собранная из переменных) страж не распознаёт — их держат согласие по тикету в уставе (необратимое — только
через `ask-owner` с поводом «необратимое») и проверка Судьи. Сбой и перезапуск без потери работы (15) и параллель без
столкновений (13) уже держат файлы состояния, замок на запуск и копия на тикет; измерение — в CP10 и CP11.

## CP14 — Надзиратель: что показала история alpha

Источник: `runs.log` и тикеты alpha (306 тикетов, $2 396 за все запуски — сумма `resolved_cost`, начисленного каждому
запуску; первая редакция этого раздела складывала `cost_usd` — итог сессии с начала, считанный повторно, — и давала
$6 932: ошибка исправлена 14.10). Три тикета — $538, 22 % всех трат: TK-048 «бэктест в 4 раза быстрее» —
6 дней, 542 запуска, $257, итог `stopped`; TK-049 — 239 запусков, $212; TK-065 — 215 запусков, $69. Возвратов Судьи у них 0–1, запуски законные (дождались задания на машине), статус
меняется — тормоза кода (2 возврата, 12 запусков без смены статуса, 6 в час) такие тикеты не останавливают. Видно это
только по смыслу лога: «цель — в 4 раза; потрачено столько-то; последние сутки ускорение не растёт». Это главное,
что должен ловить Надзиратель: деньги и время идут, а к цели не движемся.

Остальное из списка CP14 код уже держит частично — Надзирателю остаётся только смысловая часть:

| что | держит код | остаётся Надзирателю |
|---|---|---|
| вопрос владельцу не по четырём поводам | владельца спрашивает только Судья и только с поводом (`routes.py`) | вопрос, на который уже есть решение В-N, — вернуть роли с номером |
| круг «чиню → ломаю» | после 2 возвратов тикет закрывается «не сделано» | исправление ломает уже принятое в другом тикете |
| срок под угрозой | «назван / прошло» — число из `due` | сколько работы осталось по логу |
| простой ресурсов | загрузка — число от проекта, считает код | — |
| уход от цели | `--ref` только на открытую цель | задача не служит цели, на которую ссылается |
