# V2: чекпоинты

Цель — продукт, который закрывает [бизнес-задачу](business-task.md) (17 критериев). План — [`plan.md`](plan.md).
Чекпоинт — проверяемое состояние ветки `v2`: что в нём есть и чем это доказано; следующий начинается только от
закрытого предыдущего. В `main` ничего не вливается до CP12: влитый PR плагина запускает автовыпуск. Плагин
универсальный: ни правил, ни машин, ни решений конкретного проекта в нём нет. Продукт принят, когда в CP13 каждый критерий «закрыто, если» подтверждён измерением.

**Как идёт работа.** Чекпоинты — подряд, без вопроса «начинать?»: план утверждён. Остановка — только на решении
владельца, и тогда первой строкой «Стою: жду вашего …». Простой 13.10 после CP2 (ждал «да» на уже утверждённое) —
нарушение этого правила; то же правило записано CEO в устав (`templates/roles/ceo.md`), тревога «готовая работа
стоит» (CP5) ловит такой простой в самой команде.

Механически не ловится — честно: трата денег (покупка серверов, платные сервисы) не распознаётся по команде; её держат
повод `ask-owner деньги` и проверка Судьи. Сбой и перезапуск без потери работы (15) и параллель без столкновений (13)
уже держат файлы состояния, замок на запуск и копия на тикет; измерение — в CP10 и CP11.

## CP0 — отправная точка (13.10)

Ветка `v2`, версия 1.10.0. Полный набор тестов: 1116 прошли, 2 пропущены, 0 упали.

**V2-1, Судья по умолчанию** (1.9.0)
- `tickets.py new` ставит `reviewer: judge` сам; без Судьи — только механические задачи Haiku, тикеты Судьи и
  закрытие тикета CEO. `new --no-reviewer` без Haiku — отказ.
- Старый тикет без ревьюера: `done`/`pr` исполнителя идут Судье, `reviewer: judge` дописывается в шапку.
- Поводы вопроса владельцу: деньги, направление, необратимое, бизнес-правило.

**V2-2, реестр владельца и помощники CEO** (1.10.0)
- `registry.py`: решения В-N (`.claude/decisions.md`), цели G-NNN (`.claude/goals/`); номер и формат ставит код,
  цитата — дословно из stdin. `--ref` тикета — только существующий номер, цель — только открытая.
- Страж: `CLAUDE.md`, реестр решений и цели — запускам ролей ни писать, ни удалять. `/rpv-init` заводит реестр и
  подключает его к `CLAUDE.md` строкой `@.claude/decisions.md`.
- Помощники CEO — его рутина дешевле, разговор с владельцем остаётся у CEO:

  | помощник | делает за CEO | модель |
  |---|---|---|

  | `reporter` | отвечает на «статус», «что делаем», «что готово» | Sonnet 5.5 xhigh |
