## CP0 — отправная точка (13.10)

Ветка `v2`, версия 1.10.0. Полный набор тестов: 1116 прошли, 2 пропущены, 0 упали.

**V2-1, Судья по умолчанию** (1.9.0)
- `tickets.py new` ставит `reviewer: judge` сам; без Судьи — только механические задачи Haiku, тикеты Судьи и
  закрытие тикета CEO. `new --no-reviewer` без Haiku — отказ.
- Старый тикет без ревьюера: `done`/`pr` исполнителя идут Судье, `reviewer: judge` дописывается в шапку.
- Поводы вопроса владельцу: деньги, направление, необратимое, бизнес-правило.

**V2-2, реестр владельца и помощники CEO** (1.10.0)
- `registry.py`: решения В-N (`.claude/decisions.md`), цели G-NNN (`.claude/goals/`); номер и формат ставит код,
  цитата — дословно из stdin. `--ref` тикета — только существующий номер, цель — только открытая.
- Страж: `CLAUDE.md`, реестр решений и цели — запускам ролей ни писать, ни удалять. `/rpv-init` заводит реестр и
  подключает его к `CLAUDE.md` строкой `@.claude/decisions.md`.
- Помощники CEO — его рутина дешевле, разговор с владельцем остаётся у CEO:

  | помощник | делает за CEO | модель |
  |---|---|---|
  | `secretary` | записывает решения и цели владельца дословно | Haiku 5.5 xhigh |
  | `inbox` | разбирает сигналы: что требует действия, что к сведению | Haiku 5.5 xhigh |
  | `reporter` | отвечает на «статус», «что делаем», «что готово» | Sonnet 5.5 xhigh |
