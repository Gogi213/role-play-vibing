## 7. Алгоритм

Алгоритм: варианты — выборка 20–30 записей вручную / полный разбор тикетов и git скриптом + ручная проверка выборки / автосверка слов требования с текстом заказа; замер — скрипт нашёл 916 возвратов на двух проектах за ~1 мин (первая версия, без `*-log.md`, — 661), словарная сверка с заказом даёт только грубую долю (русская морфология, «договор» часто в архиве лога), класс «прочее» оказался размыт (настоящего «прочего» 0 из 14 в выборке); выбран — скрипт (воспроизводим) + ручная выборка 27 для причин, автосверка слов только как второй признак, потому что вручную 746 возвратов не размечаются, а по ключевым словам причина не определяется.
Не проверено: «пункт был в договоре» для alpha — договор в лог-записях alpha обычно отсутствует (заказ в описании тикета), поэтому «договор» там = описание; «ничего (то же сдано)» в исследовательских тикетах alpha может означать результат на сервере без коммита — $74 на круги «ничего» верхняя оценка.
