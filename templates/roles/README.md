# Команда ролей под диспетчером

Владелец говорит с `CEO`; работу делают `Исследователь`, `Инженер`, `Судья` — сессиями CLI под диспетчером, одна сессия на тикет.

## Состав

| роль | зона |
|---|---|
| `CEO` | долгая сессия (`/ceo`): приоритеты, задачи, устав и хуки `.claude/roles/`, `.claude/hooks/` |
| `Судья` | проверки и вердикты (`docs/reviews/`) |
| `Исследователь` | исследования, отчёты, расчётные скрипты |
| `Инженер` | код, тесты, сборка, инфраструктура |

Чужую зону не правишь — запись в тикете. Коммит — только своих файлов, префикс `[CEO]`/`[Исследователь]`/`[Инженер]`/`[Судья]`.

## Тикет

- Работа — тикет `.claude/tickets/<ID>.md`: состояние в шапке (`status`, `wait_for`, `next`) и `## Лог`; статус правишь сам.
- Итог шага — командой `result <ID> <done|pr|accept|return|blocked|ask-owner|wait> --why "..."` (из вставки хука; доказательство: `--path`, `--pr --sha`; `--why` ≤ 200 знаков). `comment` — промежуточная заметка без смены хода.
- Кого будить дальше, ставит код по таблице маршрутов; `--next` руками не ставь. `@роль` в тексте никого не будит. `blocked` и `ask-owner` исполнителя идут Судье; владельцу — только `ask-owner` Судьи.
- Долгая работа — только `tools/jobrun.sh <метка> -- <команда>` и `wait` на `job:<алиас>:<id>` или файл итога (`file:`/`host:<алиас>:` + `RC=<путь>`), срок `--by` по темпу; `wait file:` на что-то иное откажет. Циклы ожидания (`sleep`/`until`/`while`) в запуске дольше ~1 мин и свои очереди (`pgrep` чужих процессов) запрещены (В-73).
- Кодовая задача — своя копия `.claude/worktrees/<тикет>`. Блокнот роли `.claude/roles/notes/<роль>.md` ≤ 4 КБ.

## Договор

Первая запись исполнителя: «Сдам · Примут, если (2–6 проверяемых пунктов) · Не входит». Каждый пункт с ярлыком: `[чтение кода]` · `[тест: <команда>]` · `[запуск: <команда>]` · `[вживую]`. Команда — только тесты самой правки (`python -m pytest <файл правки>`), полный прогон делает зелёный CI PR (`has_ci`, умолчание `true`; при `has_ci: false` — полный прогон в «Итог»); приёмка перезапускает команду, код ≠ 0 — отказ. Обязательно: «Где ещё это живёт» (все писатели и вызывающие по приёмнику сигнала, не по имени функции, с командой поиска) и, для нового парсера, регэкспа или стража, «Таблица граничных входов» (`0`, пусто, отрицание, другой регистр, пробелы, ОС). `[вживую]` — на настоящей машине и данных малым срезом, Судья смотрит сам.

## Правила

- Делай то, что сказано, и как сказано; двоякая постановка — вопрос до работы.
- Новые задачи — только по слову владельца (запись реестра: В-N или G-NNN); `--ref` тикета — её номер.
- Шаги цели ведёт диспетчер. Хвост по силам ролям — тикет, не `ceo:`.
- Числа владельцу — после Судьи; оценка — не замер, помечать «оценка».
- Изобретённое число запрещено: измеримое измеряется, назначаемое — решением владельца.
- Ошибка исправлена, когда есть проверка из git, падавшая до исправления и проходящая после; объявляет Судья.
- Публикация и удаление — по правилам стража; удалять ветки на удалённом нельзя.
