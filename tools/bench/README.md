# Замеры плагина

Одни и те же замеры на Linux и macOS, один сводный отчёт. Только stdlib, POSIX (Windows — `tools/e2e_clean_project.py`).

```
python tools/bench/run.py                          # бесплатное: микробенчи + оркестрация на заглушке, ≈ 15–20 мин
python tools/bench/run.py --live smoke             # + задача hello с моделями (≈ $0.3)
python tools/bench/run.py --live core --repeat 2 --budget-usd 20
python tools/bench/compare.py bench-a.json bench-b.json   # две машины рядом, ⚠ — расхождение ≥ 1,5×
```

В CI — workflow `bench` (ручной запуск, Ubuntu и macOS): бесплатная часть всегда, живая — с секретом `CLAUDE_CODE_OAUTH_TOKEN`
и входом `live`. Сводка попадает в Summary запуска и в артефакт `bench-comparison`.

## Что меряется

| часть | что | деньги |
|---|---|---|
| `micro` | холодный старт каждого скрипта, операции с тикетами, рост времени от числа тикетов (10…2000), задержка каждого хука, размер вставки в сессию роли, набор тестов (параллельно и подряд, повторы), страж: 48 случаев «ожидание против факта» + попытки обхода + подмена роли в CLI | нет |
| `stub` | настоящий диспетчер, но вместо `claude` — заглушка: задержка передачи хода, круг «вернуть → переделать», пачка тикетов (параллель по умолчанию и 3), падение диспетчера посреди хода, сбои ролей и сигналы CEO/Telegram, простой (CPU, память, рост каталога) | нет |
| `e2e` | чистый проект → `/rpv-init` → цель → тикет → роли с моделями → принятие Судьёй; время по фазам, токены и цена по ролям и моделям, время инструментов против времени модели, **проверка результата кодом отдельно от Судьи** | да |

Живые наборы (`tasks.py`): `smoke` — hello; `core` — hello, fizzbuzz с тестами, исправление ошибки с записью в реестр, CLI из
нескольких файлов, исследование с таблицей «число · файл:строка»; `full` — core + ловушка стража (приказ запушить в main и
удалить каталог вне проекта) + три тикета параллельно + SIGKILL диспетчера посреди хода. Текст задач одинаков везде.

## Как читать

- **Мёртвое время** (`dead_share`) — доля времени тикета, когда не работала ни одна роль: опрос, паузы, подхват. Это вклад плагина.
- **Судья против проверки кодом** — «ЛОЖНОЕ ПРИНЯТИЕ» значит, что Судья принял, а результат не проходит независимую проверку.
- **Учёт расходится** — плагин насчитал в `runs.log` не ту цену, что сообщил CLI по итогам запусков.
- Токены зависят от окружения машины (глобальные навыки, MCP). Сравнивать ОС — только в одинаково чистом окружении (CI).
- Заглушка (`stub_claude.py`) мгновенна и платит условные $0.0123 за ход: её числа — задержки плагина, не модели.
- Для подхвата роли после перезапуска диспетчер сверяет имя образа процесса со словом `claude`; заглушка — Python, поэтому
  `bench_dispatch.py` подменяет эту одну константу. Боевые константы (тик 15 с, паузы) не трогаются.
